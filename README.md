# dCC Capstone

This project is a full-stack web application built with Django and React, using JWT-based authentication to support a secure user experience across the frontend and backend. The application combines a Python REST API with a React client to provide a bookstore-style experience with user accounts, protected routes, and searchable book-related features.

## Project overview

The repository includes:

- A Django backend powered by Django REST Framework
- JWT authentication and authorization setup for secure API access
- A custom user model for future role-based access patterns
- Multiple example apps, including authentication, comments, bookshelves, cars, and points
- A React frontend using React Router for protected pages and multi-page navigation

This capstone project demonstrates how to connect a Django backend to a React frontend in a modular, full-stack application structure.
